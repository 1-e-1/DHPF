# DHPF

Research code for a structured second-order generative field with shared moving
sources, radial and tangential kernels, and endpoint distribution learning.
The repository includes toy-distribution experiments, generative-model comparisons
and multivariate time-series studies.

## Project layout

- `experiments/`: mathematical checks and initial two-dimensional experiments.
- `benchmark/`: fixed-protocol comparisons, data generation, training and reporting.
- `research_ts/`: time-series studies, analysis and manuscript-generation scripts.
- `paper/`: historical manuscript text and figures.
- `docs/HISTORICAL_OVERVIEW.md`: the original experiment overview, retained as a historical record.

## Important artifact status

As of the 2026-10-24 public export, the external directory previously holding the
original datasets, checkpoints and raw results had been deleted locally. Those
artifacts are **not available in this repository**. The retained manuscript numbers,
figures and historical overview have not been independently reproduced for this
release. They must not be interpreted as results generated by a fresh clone.

This code-only release can support new experiments; it is not a complete historical
reproduction package. New runs do not restore the original splits, weights or evidence.

## Setup and small checks

Install a compatible PyTorch/torchvision pair in a dedicated environment, then:

```sh
python -m pip install -r requirements.txt
python experiments/check_math.py
```

The mathematical check runs on CPU and does not train the research models.
`python -m benchmark.checks` additionally checks model structure and gradients;
it writes a new check report under `results/checklist_v1/E01/`.

Inspect training budgets before using `benchmark.worker` or `research_ts.study`.
Do not interpret historical commands as a request to launch the full training queue.
Dataset generators are in `benchmark/data.py`; externally hosted datasets remain
subject to their original terms. Paths are relative to the cloned repository.

## Optional manuscript tools

Core model code does not require Codex or personal skills. Some historical figure
and document QA scripts require external optional helpers. Set
`NATURE_FIGURE_SCRIPTS` to an installed nature-figure helper directory and
`DOCUMENTS_SKILL_DIR` to an installed document-rendering tool directory to use those
optional scripts. These helpers are not bundled and are not necessary for model checks.
Windows COM-based Word rendering is optional and platform-specific.
